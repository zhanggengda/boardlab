# 板演｜虚拟主板实验室

板演 MVP 的静态网站发布目录，包含浏览器运行所需的 HTML、JavaScript、样式与资源。

- 主入口：`index.html`
- 手机摄像头入口：`phone-camera.html`（从电脑端生成配对链接）
- 网站通过 HTTPS 提供，无需 ChatGPT 登录。
- 工程和媒体存储在访问者浏览器中；更换网站域名后，可先从原站导出工程，再在新站导入。

本仓库只存放已公开网站的静态发布产物。

当前界面已合并原站第40版与图片拖放功能，资源版本为41.0。主源码在 `k10-studio/dist`；镜像与电脑账号版通过主源码的 `scripts/sync-mirrors.mjs` 同步并逐文件校验。此公开镜像保持公开访问，账号版另由服务器执行登录权限校验。
